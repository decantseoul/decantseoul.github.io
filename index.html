  • 웹 검색 한도가 조사 도중 소진돼 국내 소믈리에·바·다이닝 소식을 더 찾지 못함. 확인된 것만 실어 총 23개(소믈리에 1·다이닝 4·바 3).
  • 전일까지 실려서 뺀 소식: 웨스틴 조선 나인스게이트×놀 갈라(11.4–5 진행), 바타시올로 15주년 디너(11.4–5), 팀 카발란 뽐, 호텔 바 한국 재료 칵테일 기획.
  • 범위 밖이라 뺀 소식: 박힘찬 소믈리에 대회 우승(10.26), 스시 카네사카 히노츠키 1분 완판(10.23 보도, 행사 11.12–14).
  • 대기 목록 정정: '월드 50 베스트 11.4'는 The 50 Best Restaurants 2026 리마 시상식(한국 시간 11.5 오전 결과). World's 50 Best Hotels 2026은 9월에 이미 발표(1위 로즈우드 홍콩).
  • 곧 나올 결과: CY SOMMS·아시아 와인 트로피 11.4 / 글렌파클라스 성수 런칭 11.5 / 본햄스 라 타슈 1945 11.7 / 국가대표 소믈리에 11.7–8 / 고미요 프랑스 11.9 / 미쉐린 태국 11.10 / RVF 주르네 뒤 뱅 11.14–15 / 오스피스 드 본 11.15 / 크리스티 드루앵 경매 마감 11.17 / 보졸레 누보 11.19 / IWSC 11.24.
  • 배치: 소피텔 콤파라 셰프 선임은 10.28에 실렸고, 이번에는 11.5–6 포핸즈 행사로 다이닝에 배치. 아만 나레 인사는 호텔에 배치.
